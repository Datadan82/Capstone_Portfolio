## How to Run

Just open `index.html` in any modern browser — **no build tools, no Node.js, no Android Studio**.  
It is fully self-contained and runs offline.

For the live submission, host it on one of:
- **GitHub Pages** (free, permanent) — push to a repo → Settings → Pages → Deploy from `main`
- **Netlify** (drag & drop the folder at netlify.com/drop)
- **Vercel** (import the GitHub repo)
